# Unidad dos Fundamentos de Inteligencia Artificial

En este repositorio se encuentran concentradas todas las actividades realizadas correspondientes a la unidad 2 de la materia

## Actividades

| Actividad | Contenido | Carpeta |
|---|---|---|
| Problema de la hormiga | Implementacion de un sistema de agentes con CrewAI para resolver y explicar el problema de la hormiga, incluyendo datos base, interfaz grafica y logica de busqueda BFS. | [01-problema Hormiga](<01-problema Hormiga>) |
| Visualizador de grafos | Aplicacion de escritorio en Python que permite comparar Dijkstra, Bellman-Ford, Floyd-Warshall y A* sobre grafos ponderados, visualizar el recorrido paso a paso y mostrar el costo de la ruta. | [02-visualizador Grafos](<02-visualizador Grafos>) |
| Algoritmo genetico binario y real | Implementacion de algoritmos geneticos con codificacion binaria y real para maximizar, minimizar y optimizar varias variables o funciones como Rastrigin, Schaffer y Schwefel. | [Algoritmo_Genetico](<03-algoritmo genetico/Algoritmo_Genetico>) |
| EvoLab | Aplicacion de escritorio que aplica programacion genetica para encontrar formulas simbolicas mediante arboles de expresion, metricas de error, seleccion, cruce, mutacion y exportacion de resultados. | [Carpeta EvoLab](<03-algoritmo genetico/Algoritmo_Genetico2>) |
| Arboria - Laboratorio de expresiones | Aplicacion web con Flask y Three.js para escribir, interpretar, visualizar en 2D y 3D, generar y comparar expresiones matematicas mediante arboles de expresion. | [Arbol_Expresion](<03-algoritmo genetico/Arbol_Expresion>) |
| N-Reinas | Aplicacion web que resuelve el problema de las N-Reinas mediante un algoritmo genetico, con visualizacion 3D animada, seleccion, cruce de orden, mutacion, elitismo e historial. | [N-Reinas](<03-algoritmo genetico/N-Reinas>) |
